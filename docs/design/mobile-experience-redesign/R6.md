# 首页搜索与图片发送体验

## 本次范围

首页搜索按钮进入独立页面，含输入框、本机历史及分组结果。搜索已加载且可见的会话
名称、私聊对方姓名／GitHub 用户名、话题标题和简介；进入时同步已授权话题目录。
精确／前缀匹配优先，再按会话最近活动排序。记录主动提交或打开结果的关键词，
最多 12 条，支持复用、删除、清空；返回结果页保留关键词。历史按服务、账号及空间隔离，
退出清理。未增加消息全文搜索或服务端搜索接口。

返回、输入和清空位于同一行，顶部安全区固定在滚动视口外。表单、反馈、历史与结果
共用一个键盘感知滚动区，搜索聚焦时独占 IME 占位，离开恢复系统 pan；查询变化不
重建输入节点，横屏不使用键盘全屏提取。公开布局刷新保持输入可见，空间保护只
比较实际输入行与当前有效 RN 键盘帧，不用视口减键盘高度猜坐标；旋转作废旧帧，
缺帧不主动收键盘。搜索可见时，同一全局错误 Notice 放在提交按钮后的滚动表单内，
避免固定横幅挤压输入；离开后恢复根提示，不清除错误或丢弃历史、话题反馈。

聊天加号提供「选择图片」和「选择文件」。图片由系统 Photo Picker 单选／多选（最多
9 张），系统确认后逐张直接上传发送；取消不发送。文字、引用、文件草稿保持，图片
各自有上传任务和 clientMessageId，失败单独重试。文件仍在输入框展示附件、允许附言，
由用户点发送。所有发送沿用 Workspace 授权、配额预留、分片及 canonical content。
页面或账号失效停止后续发送；已预留 ID 与已上传附件保留原身份供明确重试。

新增 Expo ImagePicker 模块要求 APK 覆盖升级至运行时 `android-5`，不申请相机、录音或
媒体库广泛读取权限。服务默认地址仍由构建配置提供，用户无需选择。
实现和回滚决策见 [ADR](../../adr/2026-10-07-search-and-photo-send.md)。
