# 手机任务流程

Web 是导航轨 + 中栏 + 正文 + 按需详情。Android 是单窗格返回栈。对象、动作和结果必须一致；栏宽、悬停和右键不必一致。

## 1. 信息架构

```text
未登录
  └─ 登录（GitHub 主按钮，邀请次要）

已登录
  ├─ 聊天 Tab
  │    ├─ 分段：会话 | 话题
  │    ├─ 会话行 → 聊天页（隐藏根 Tab）
  │    │     └─ 详情（全屏，默认关闭）
  │    │           └─ 文件预览／系统选择器（系统层，返回恢复锚点）
  │    └─ 话题行 → 同一聊天骨架（R2）
  ├─ 文件 Tab    文件库，独立于当前会话发送
  ├─ 成员 Tab    可见联系人 → 发起私聊 → 聊天页
  └─ 我的 Tab
       ├─ 个人资料（R1 只读）
       ├─ 外观与阅读（本机）
       ├─ 通知（系统权限说明）
       ├─ 空间信息（只读）
       ├─ 关于与更新
       ├─ 组件工作台（仅 __DEV__）
       └─ 退出登录（独立确认）
```

宽屏／横屏：初版保持居中单窗格。空间足够时以后可以列表+聊天两栏，禁止三栏，禁止把气泡拉满平板宽度。

## 2. 关键任务

### 登录

发布包：标识 +「共享空间」一句 + GitHub。不选服务、不做通道、不进空间二次确认。可选邀请只接受当前 origin。取消 OAuth 回到可再点的登录页，不转圈。成功进入聊天列表。

### 打开会话并返回

列表点按只在抬起时导航，按下期间行不能被新消息换成另一个对象（R2 补排序锁定；R1 先稳定行结构）。聊天页原生标题=会话名，右侧「详情」。返回列表保留筛选与分段。切到文件 Tab 再回来，仍在聊天列表而不是残留详情。

### 发一条文本（当前已有，R1 不改协议）

编辑器在底部。回车换行，按钮发送。草稿按会话保存在本机。失败可重试同一 `clientMessageId`。R2 才加引用条、附件预览、@ 和表情面板。

### 发文件（当前缺口）

现状：聊天里点「文件」会选系统文件、上传并立刻发消息。目标流程：选文件 → 在输入区预览 → 用户点发送 → 上传与发送分状态。取消选择器必须无消息。R1 不把错误流程包装成新能力。

### 设置外观

我的 → 外观与阅读 → 跟随系统／浅色／深色。立即应用到本机，不调用账号 API，不重建草稿。失败只表示本机没记住，当前页仍可继续使用所选模式。

### 通知

我的 → 通知：说明本地通知、后台可延迟、打开系统权限。会话级 `all/mentions/muted` 仍在该会话详情。系统拒绝时文案是「系统未允许通知」，不是「通知已启用」。

### 退出

独立危险区，确认后清 token、草稿、缓存和通知。返回键不能触发退出。

## 3. 返回栈

| 当前层 | 系统返回 |
| --- | --- |
| 键盘或 IME 候选 | 先收起键盘 |
| Dialog／动作面板／表情面板 | 关闭浮层，焦点回触发控件 |
| 详情 | 回聊天，保留草稿 |
| 聊天／话题 | 回列表，保留筛选 |
| 设置子页 | 回「我的」目录 |
| 根 Tab | 交由系统（通常移到后台），不登出 |
| 强制更新 | 拦截返回 |

从通知打开会话：上级是聊天列表，不是空栈。R2 补话题目标。

## 4. 状态几何

加载、空、错误、离线缓存使用同一页头和列表／聊天骨架，只替换中部说明。无权、已关闭话题、空间关闭使用明确终态，不伪装成「还没有消息」。错误贴在失败对象旁；全局 Notice 只用于会话级／账号级故障。
