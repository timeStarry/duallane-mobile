# 开放依赖

记录 R0 时已知、会影响后续阶段的依赖。客户端不得用占位成功掩盖这些项。

## 1. 可在本仓推进（不阻塞 R1）

| 项 | 说明 | 阶段 |
| --- | --- | --- |
| 原色 token 与 primitives | 不需要服务端变更 | R1 |
| 导航壳、登录、列表行、设置目录 | 不需要服务端变更 | R1 |
| 开发工作台 | `__DEV__` 可见，使用正式组件 | R1 |
| 扩展 `parseMessage` 投影 | 主仓 DTO 已有字段 | R2 已接 |
| 回复／反应／隐藏／撤回／常驻 HTTP | 路由已在 `core_routes.go` | R2 已接 |
| 话题 HTTP | 路由已在 `topic_routes.go` | R2 已接；不做关闭／归档管理 |
| 表情库与卡片 | 路由已在 emote／card | R2 选择器／话题卡已接；表情包管理工具未做 |
| 资料 `PATCH /me/profile` | 路由已在 | R1 已接显示名／查找可见性；头像上传仍待 |
| 自动折叠偏好 | `GET/PUT /me/emote-settings` 已有 | R1 已接设置保存；消息流折叠属 R2 |

## 2. 阻塞或需主仓确认后再做

| 项 | 现状 | 处理 |
| --- | --- | --- |
| 设备会话列表与撤销 | 移动方案有目标；当前页面与本轮核对未找到可对 Android 安全展示的完整列表／撤销契约 | 不放假入口。确认 Go 路由、字段和撤销语义后再开 |
| 外观跨端同步 | 无账号级主题契约 | 只做本机；文案不得写「已同步」 |
| 跨设备草稿 | 无契约 | 本机按账号+会话保存 |
| 通用消息编辑、转发、全文搜索 | 无完整当前契约 | 不做，不画入口 |
| 远程推送／FCM／保活 | 明确不做 | 本地通知保持现状 |
| 邮件通知渠道设置 | Web 个人设置有；移动端不管理 ntfy／邮箱服务端配置 | 不在「我的」做渠道管理页 |
| Bot 管理、空间管理 | 范围外 | 不进入 Android 信息架构 |
| 更多主题家族 | Web 有五套；R1 只原色 | 以后适配，不提供无效选项 |
| 成员 GitHub 登录、备注字段 | 主仓 DTO 有，bootstrap 移动 schema 未收 | R2 扩展解析后再展示 |

## 3. 文档与实现不一致（已记录，不以页面现状当新标准）

- 旧移动方案第 4、5、14 节的「最小聊天」阶段划分已被本改造要求取代。
- `AGENTS.md`／架构中的「设备会话」是原方案目标，不是已实现事实。
- Web 一级导航是「聊天、话题、文件、成员、个人」；Android 用聊天首页分段承接话题，这是布局决策，不改变话题对象。
- Web 触控下限 44px；Android 主要动作 48dp。
- 当前 APK 的联通性验证不能填 [ACCEPTANCE.md](ACCEPTANCE.md)。
