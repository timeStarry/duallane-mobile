# 聊天表情、媒体与相邻问题修复

## 行为与兼容

本次修复五项反馈：选中的自定义表情按 Web 的 `emoji` block 发送；独立表情与图片
不用气泡、尺寸与圆角一致并可点击预览；大图关闭避开状态栏，透明小按钮保存到手机；
文件列表右侧下载图标；所有文字消息完整圆角，长按替代逐条三点。

服务端原先收到 `[custom:UUID]` 的普通 text block，所以 PC 按文本显示。现在只把
表情面板明确选中的资源转换为 `{type: 'emoji', shortcode: 'custom:UUID'}`，跟随 Web
的资源身份；手写、粘贴、代码和旧草稿里的字符串不自动变为资源操作。`emoteSpans`
是本机草稿可选字段，文本编辑同步平移或使选区失效，旧缓存兼容。点击直接发送只发
所选表情，不消费已有文字、提及、引用或附件草稿；正常发送与重试保留同一身份。

只涉及 Android Workspace 客户端；不改变 P2P、服务端 API、权限、配额、审计或保留。
附件预览与保存沿用服务端校验及额度预留；表情预览重新授权逻辑资源后使用账号隔离
缓存，不作为附件下载预留额度。没有新增原生依赖或权限，运行时保持 `android-5`。
默认生产地址继续由构建配置设置为 `https://duallane.tsio.top`，无需用户选择。

## 相邻审查

- 表情目录、分享与导入、收藏：账号／API／页面代次守卫，迟到响应不能污染新账号。
- 图片和表情预览：逻辑资源重新授权、隐藏／撤回／删除和话题退出守卫；媒体注册
  尚未切到新账号时拒绝使用旧客户端；旧图片回调不能作用于新源。
- 大图路由与合集弹窗：独立全窗口安全区，四边留白；离开路由与强更时关闭遮挡层，
  减少动画设置保留。嵌套图片长按和消息辅助动作保持可达。
- 文件页及会话详情复用 FileRow 的下载图标与明确名称；共享卡片保留自己的菜单，
  不把聊天三点的移除扩展为移除所有对象操作。
- 普通文件选择的图片附言和 Web 发送的混合图片消息按媒体分段；文字保留圆角气泡，
  图片直接展示，引用／反应／时间／重试仍属于同一个逻辑消息。
- 旧提及草稿仍提示重新选择成员；新增表情选区不能改变旧身份提示或异步草稿保留。
