# R5：2026-10-06 移动端验收与修复

本轮从正式 `v0.2.1`（`10160ce5247e984de586515dafd4285b29248d30`）开始，
分支为 `codex/mobile-acceptance-20261005`。本记录将源码回归、旧包实测和候选包实测
分别列出；部分路径通过不代表 [完整验收账本](ACCEPTANCE.md) 整行通过。

## 修复范围

- 历史／回复定位入口不提前标记最新消息已读；前台实际返回最新后串行提交已读。
  跨页引用按当前目标请求 `around`，窗口变化时重新读取，不用旧快照覆盖撤回状态。
- 恢复隐藏消息重新获取服务端 canonical content；迟到 HTTP、发送、上传和消息动作
  回包需要当前账号及群／话题权限，不能把已撤权内容重新放回缓存。
- 提及记录成员身份和 UTF-16 文字跨度，同名成员、删改和旧草稿不猜测身份。
  编辑旧草稿时需要重新选择候选，界面给出提示。
- 消息支持 450 ms 长按、显式入口及辅助技术动作；打开动作／表情菜单收起键盘并保留
  草稿。反应支持完整合集，动作失败在当前消息显示原因和重试路径。
- 已发送话题消息可明确同步到群／取消同步。服务端投影列表最多 200 条且没有分页，
  满窗口时不能确认的较早消息禁用该动作并说明原因，不把未知状态当作未同步。
- 媒体缓存使用当前服务端授权；账号、父群、话题或下载权限失效清除缓存。
  历史消息从最新分页窗口移出不等同于撤权。下载／分享失败可见且阻止重复提交。
- Echo 需求卡显示 canonical 的详情、场景、期望结果、处理说明及中文状态；失效／受限
  卡片不保留业务 payload，迟到卡片回包不覆盖新对象。传输错误补齐 Cronet 固定错误码
  分类，只记录既有安全枚举，不记录原始异常、URL、请求头或内容。
- 官方 Echo 私聊加入普通成员的需求／反馈引导及两个 slash 命令；支持本机分步骤草稿、
  退出恢复、取消与明确的最终确认。GET 脱敏字段不回填原文；冲突只恢复当前 revision，
  不自动提交。慢命令回包仅清理仍是原对象的草稿，新增引用／附件／提及保留。
- 反应目录与消息发送目录分离：只展示当前 Go 服务端承认的 667 个内置键；收藏和
  自定义合集仍可作为消息发送，不伪装成服务端不支持的 reaction。快捷／目录反应
  使用同一 canonical key，已选项目再次点击可移除。
- 实时协议按 Go 外层 `version: 1` 校验，内部事件无需重复版本字段；缺失／未来版本
  仍走安全同步，不把服务端正常帧误判为未知协议。重复事件不重复应用／通知，重放不通知。
- 同一 `cardId` 的版本事件定点刷新已挂载卡片，前台重连的授权快照恢复漏失事件；
  账号、API、父群／话题或读取权限变化立即丢弃旧卡片模型与迟到响应。
- 快捷与完整目录的当前反应都显示选中底色，并提供辅助技术 `selected` 状态。
- 字体修复最终改为稳定 SDK 55 配套运行时，由上游处理字体布局更新并移除应用 reload；
  Activity 保留 `fontScale` 与原 IME／导航配置，详见 [原生运行时 ADR](../../adr/2026-10-06-android-font-layout-runtime.md)。
  旧 reload 候选在 API 35/36 失败，不作为交付方案；升级后完整原生门禁及真机回归待记录。
- 手动 CI 可填写候选版本及 versionCode，复用正式签名并只输出 artifact；不会创建
  GitHub Release。正式包默认服务仍由构建环境注入 `https://duallane.tsio.top`。

以上只修改 Android Workspace 客户端，不修改服务端存储、配额、审计及 P2P。
新增提及元数据属于本机草稿，出站消息继续遵循现有版本化协议。
