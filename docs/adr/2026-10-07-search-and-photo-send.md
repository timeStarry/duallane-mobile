# 首页搜索与系统图片快捷发送

## 用户行为与边界

首页搜索进入独立 Stack 页面：输入框、仅本机的历史搜索词、会话和话题结果。
输入时筛选当前账号已授权、已加载的会话名称、私聊对方名称／GitHub 登录名，以及话题
标题／简介，明确说明范围，不宣称消息全文搜索。会话精确／前缀匹配优先，再按最近活动；
进入搜索页同步一次当前可读的话题目录，关键词仍不进入 API。
提交搜索或打开结果时记录关键词；不逐次记录输入。历史最多 12 条，去重后最近优先，
可单条删除或全部清空。键使用已有账号隔离的缓存前缀，退出登录随账号缓存删除；
空账号不读写，历史及关键词不进入 API、日志或遥测。

聊天「添加」增加「选择图片」。系统图片选择器允许单选／多选，确认即逐张上传并发送，
无需再点聊天发送按钮。取消不上传、不发消息；选图过程不消费文字、回复或文件草稿。
每张图片有独立的 clientMessageId、上传任务和失败重试。原「选择文件」保留附言和明确
发送流程。对话／话题目标、账号、API、权限或页面失效后停止迟到的发送，不转发到新目标。

## 运行时与数据影响

增加 Expo SDK 55 配套的 `expo-image-picker`（Expo 官方维护、MIT），使用 Android 系统
Photo Picker，`legacy: false`、仅图片、不开裁剪、不开相机或麦克风。不申请媒体库的
广泛读取权限；只读取用户选定的缓存副本。API 26+ 沿用原生库的平台回退。
选择数量上限 9，在系统选择和返回校验两处约束。沿用已存在的账号隔离上传目录、
配额预留、分片哈希和 canonical attachment；后端权限和配额拒绝不能被客户端绕过。
成功、取消或失效时清理仅由应用创建的临时副本，失败任务按现有重试机制保留。

新原生模块要求 APK/AAB 覆盖安装，运行时升至 `android-5`，不能向 `android-4` 包通过
OTA 下发调用该模块的 JS。搜索历史使用已有可丢失 SQLite KV，不改变数据库 schema；
Workspace 消息协议仍为 v1，服务端无新接口、迁移或重复 writer。

## 验证与回滚

定向回归覆盖搜索导航、关键词提交／去重／隔离／删除、结果打开和空态；图片取消、
单选／多选、数量及媒体校验、草稿保留、目标失效、失败重试幂等和清理。
运行 pnpm check、原生插件检查、Android export、正式签名构建／安装，并在已授权真机
以合成图片验证系统选择器确认后直接发送、取消及文件原流程。记录未运行的设备边界。
回滚到旧 APK；历史为可丢失本地数据，旧客户端不读取新键。服务器协议保持兼容。

依据：[Expo SDK 55 ImagePicker](https://docs.expo.dev/versions/v55.0.0/sdk/imagepicker/)。
